In a functional language, the inverse problem occurs: adding a new data type is easy (add a new variant to a sum type), but adding a new operation requires updating all pattern matches.To bundle all operations for a type together and allow easy addition of new types, functional languages use a Record of Functions (often seen in Church encoding or Object Algebras). Instead of distributing functions across modules, you package a type's entire interface—its primitive operations—into a single record or dictionary.Bundling Operations: You define a record (or dictionary/struct) where fields are functions that operate on or produce the data type.Defining New Types: You instantiate the same record structure with a different implementation for a new data type or variant, keeping the operation suite cohesive.
