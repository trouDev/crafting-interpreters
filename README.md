# Crafting-Interpreters

This repository contains my personal implementations of the tree-walk interpreter (**jlox**) and the bytecode virtual machine (**clox**) from Bob Nystrom's excellent book, [*Crafting Interpreters*](https://craftinginterpreters.com).

I am also going to be completing the challenges that are in each chapter

## 📂 Repository Structure

The repository is organized by implementation language, keeping the Java and C toolchains completely separated:

```text
├── jlox/          # Part II: Java implementation (Chapters 4–13)
├── clox/          # Part III: C implementation (Chapters 14–30)
├── README.md      # Project overview
└── .gitignore     # Multi-language build exclusions
```
